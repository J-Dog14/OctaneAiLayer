Velocity trends

Thick lines are athletes whose latest velocity change cleared the measurement-noise band. Captures are plotted by order, not date, so trajectories line up.
How to read this

Each cell shows the athlete's latest session mean and, underneath, the change from their previous capture. Colour is only applied when the change cleared that metric's measurement-error band and the metric has an agreed better direction — green toward better, red away. A grey change is inside the noise: it did not move. A dash means we have only one capture, so there is nothing to compare.

The attention score is deliberately simple: three points per real decline, four for a real velocity drop, one and a half for a capture gap over 120 days, half a point for a single-session athlete. It sorts the page; it is not a rating of the athlete.
